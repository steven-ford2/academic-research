# Scientific literature and evidence pipeline

Planned modules: Zotero integration; identifier normalization; OpenAlex/Crossref/Semantic Scholar searches; lawful full-text acquisition; deduplication; dated queries; forward and backward citation networks; sources and quote locators; correction/retraction monitoring; study extraction and conflicting evidence.

Evidence states: `unverified`, `located`, `checked`, `disputed`, `retracted`. Passing schema validation does not mean a source was read or that a claim is supported.

See [seed claim records](evidence/claims.json). Subject-matter verification, structured reviews, and DOI clients are future work.
