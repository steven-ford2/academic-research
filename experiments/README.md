# Future experimental software engineering

Do not begin building participant-facing experimental systems before protocols, requirements and data governance are approved.

## Planned capabilities
- PsychoPy experiment generators driven by a versioned approved experiment specification.
- Unity/XR prototype architecture for VR interactions, instrumentation, event logging and device integration.
- Verified randomization/counterbalancing and stimulus-to-condition mapping.
- Time synchronization, eye-tracker calibration, timing/motion-to-photon testing, dropped-frame and data-quality analysis.
- Synthetic participants and automated regression tests where appropriate.
- Hardware-in-the-loop validation prior to claims of precision and deployment.

Automated simulation tests do not substitute for timing verification on the target display and input hardware.
