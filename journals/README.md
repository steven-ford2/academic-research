# Journal intelligence pipeline

This is a candidate registry, **not a ranking**. Collect scope and article-type requirements; publication histories; editors and publicly visible scholarly networks; common methodological critique; actual current submission rules including AI restrictions; fees and open-access options.

Never identify confidential reviewers or assert that an individual will be assigned. Distinguish public potential reviewer expertise from insider knowledge. Revalidate official author instructions immediately before submission. Current profiles are deliberately unverified and fail release checks.
