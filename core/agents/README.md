# Agent architecture and handoffs

Agents are **tools and roles**, not independent scientific authorities. Each produces dated artifacts, source links, decision logs and unresolved issues.

| Role | Output | Cannot approve |
|---|---|---|
| Discovery | Search queries, results, metadata and date | Exhaustiveness |
| Evidence extractor | Evidence table, source locators and uncertainty | Source support without primary-text check |
| Statistical engineer | Reproducible computation, diagnostics and test fixtures | Scientific inference |
| Scientific skeptic | Contradictions, confounds, alternative explanations | Final interpretation |
| Journal analyst | Dated policy and comparative fit dossier | Actual reviewers or acceptance |
| Review synthesist | Protocol, screening record, extraction and meta-analysis | Exclude studies without justified rules |
| Grant analyst | Funding sources, award history, eligibility and resources | Investigator-authored aims |
| Release controller | Blocking issues and compliance records | Override human approvals |

Independent review requires substantive methodological separation, not multiple identical language-model prompts.

Every agent run must record inputs, source versions, outputs, validation result, unresolved discrepancies, and person or process responsible for release.
