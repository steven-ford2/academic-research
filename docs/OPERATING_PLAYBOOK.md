# Daily operating playbook

## Codex cycle
1. Read AGENTS.md, current issue, source protocol and acceptance criteria.
2. Perform bounded implementation work on a branch; document decisions.
3. Execute lint, unit tests, end-to-end smoke tests and safety scans.
4. Produce PR with test outputs, known errors and scientist review questions.
5. Require human resolution of major inference and interpretation disputes.

## Literature intake
Define population/construct/outcome, searches and databases; export dated raw search results; reconcile duplicates; acquire licensed full text when permissible; record paper-level design and effect estimates; independently check extraction.

## Statistical intake
Confirm data rights, variable dictionary, measurement timing, questionnaire scoring, statistical unit and contrast coding. Freeze source and derived hashes before reproducing original results. Then perform blind sensitivity and validation analyses.

## Review protocol
Use a documented PRISMA-aligned protocol as applicable, independent eligibility/extraction where indicated, correctly specified synthesis unit, and risk-of-bias tool chosen by study design.

## Manuscript release
Scientific claims first, journal alignment second, prose/formatting third. For constrained journals, do not generate substantive AI-authored article content contrary to policy.

## Grants
Verify funder rules and eligibility before any content production. Investigators own aims, central hypothesis, rationale and substantive writing. AI may support metadata, analysis and checks within funder constraints.
