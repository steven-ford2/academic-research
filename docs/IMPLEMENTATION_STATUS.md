# Implementation status

2026-10-14: foundation alpha in public GitHub repository.

## Implemented
- Repository, Codex operating instructions, scientific project documentation.
- Minimal Python CLI for status, project creation, evidence-ledger schema audit and journal-profile currency check.
- Tests and GitHub Actions quality workflow (execution status must be verified separately).
- Evidence claims and journal candidates recorded as **unverified/located**, not released.
- Experiment 2/3 first-project audit specification and original dissertation public link.

## Not implemented
- Connected Zotero, OpenAlex or bibliographic harvest with verifiable full-text checking.
- Ingestion of original experimental datasets and reproducing any statistical models.
- Reviewed article manuscript, validated journal ranking, systematic review/meta-analysis, grant proposal or experiment.
- Automated submission, journal editor network, qualified independent peer-review, data release approval.

## Blockers
- Original raw datasets, derived datasets, mouse-video tracking code/logs, model scripts, measures/codebook and validation checks.
- IRB/ownership and coauthor review; previous overlapping manuscripts.
- Journal-specific AI and authorship requirements.
- Private repository configuration before handling any nonpublic material.
